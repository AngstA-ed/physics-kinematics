## Make-It-Make-Sense Answers

1. Same work, but motor A takes 2.0 s and motor B takes 8.0 s — one-fourth the time. Since P = W/t, motor A has **four times** the power of motor B. · *Rubric:* identifies same work AND the 4× factor from the time ratio. · NYSSLS: HS-PS3-1
2. Rearrange P = W/t → W = P·t = 60 W × 10 s = **600 J**. · *Rubric:* correct rearrangement AND 600 J with unit. · NYSSLS: HS-PS3-1
3. The faster climber did **not** do more work — both climb the same height, so both do the same work against gravity. The faster climber did that same work in **less time**, so they have more **power** (P = W/t). · *Rubric:* corrects "more work" to "same work, less time, more power." · NYSSLS: HS-PS3-1

## Exit Ticket Answer

(a) P = W/t = 48,000 J ÷ 8.0 s = **6000 W** (6.0 kW).
(b) Same work in twice the time → **half the power = 3000 W**.
(c) Work first: W = F·d = 700 N × 4.0 m = 2800 J. Then P = W/t = 2800 J ÷ 5.0 s = **560 W**.

*Tolerance/rubric:* (a) shows W/t and 6000 W; (b) 3000 W with "twice the time, half the power"; (c) computes W = 2800 J then P = 560 W. 1 point each. NYSSLS: HS-PS3-1.
