## Guided Notes

**Big idea:** An **atomic model** is a picture of the atom that scientists __________ whenever new evidence appears.

The progression (oldest → newest):

![Five-panel progression of atomic models: Dalton solid sphere, Thomson plum pudding, Rutherford nucleus, Bohr orbits, and the quantum electron cloud.](figures/atomic_model_progression.png)

- **Dalton** — the atom is a tiny, solid __________ (no inside parts).
- **Thomson** — discovered the __________ (negative); pictured them stuck in a positive "pudding."
- **Rutherford** — the gold-foil experiment showed the atom is mostly __________ space with a tiny, dense, positive __________.
- **Bohr** — electrons travel in fixed __________ around the nucleus (sets up Lesson 03).
- **Quantum** — electrons are best described as a __________ cloud (probability), not fixed paths.

**The gold-foil evidence:**

![Gold-foil scattering: most alpha particles pass straight through while a few bounce sharply off the tiny dense nucleus.](figures/gold_foil_scattering.png)

- Most alpha particles passed __________ through → the atom is mostly empty.
- A few bounced sharply __________ → there is a tiny, dense, positive __________.

## Worked Example

**Problem.** A classmate says, "The newest model proves all the old models were wrong, so they were useless." How would you correct this using the idea of evidence?

**Solution.**
1. Each model was the __________ explanation for the evidence available at that time.
2. A model changes when new __________ appears that the old model cannot explain.
3. So the old models were not useless — each one __________ the next. (Thomson's electron survived into every later model.)
