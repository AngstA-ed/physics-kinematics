Make-It-Make-Sense Answers

  1. The plum-pudding model spread the positive charge thinly across the whole atom. A soft, spread-out positive charge could only nudge an alpha particle slightly — it could never bounce one straight back. A sharp rebound requires a tiny, dense, concentrated positive region, which the model didn’t have. · Rubric: contrasts spread-out charge (Thomson) with concentrated charge (nucleus). · NYSSLS: SEP — Developing and Using Models
  2. The mass is concentrated in the nucleus, the tiny, dense, positively charged center; the rest of the atom is mostly empty space holding the light electrons. · Rubric: names the nucleus AND “tiny/dense/center.” · NYSSLS: SEP — Developing and Using Models
  3. It could change. The quantum model is the current best fit to today’s evidence, but if scientists found a new observation it could not explain, the model would be revised again — that is how all atomic models developed. · Rubric: “current best model” + “could change with new evidence.” · NYSSLS: SEP — Developing and Using Models

Exit Ticket Answer

  1. Rutherford’s model first included a tiny, dense nucleus; it was supported by the gold-foil scattering experiment (most alphas pass through, a few bounce back).
  2. Thomson’s model correctly included negative electrons inside the atom (and a positive part to balance them).
  3. Because new evidence appears that the old model cannot explain; scientists revise the model so it fits all the observations.

Tolerance/rubric: (a) “Rutherford” + “gold foil”; (b) any correct feature (electrons present / atom has + and − parts); (c) “new evidence the old model can’t explain.” 1 point each. NYSSLS: SEP — Developing and Using Models.
