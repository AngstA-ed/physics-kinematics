## Make-It-Make-Sense Answers

**1. Artifact with 1/8 of its carbon-14 (half-life = 5,730 years):**

- (a) Number of half-lives: 1/8 = (1/2)³ → **3 half-lives**.
- (b) Age: total time = number of half-lives × half-life = 3 × 5,730 yr = **17,190 years**.

Step-by-step: Write the fraction remaining as a power of one-half. 1/8 = (1/2)³, so the sample has been cut in half 3 times → 3 half-lives. Multiply by the half-life: 3 × 5,730 = 17,190 years.

*Rubric:* 1 point for correctly identifying 3 half-lives (from 1/8 = (1/2)³, not "8 half-lives"); 1 point for the correct age (17,190 years) with the multiplication shown. A student who writes "8 half-lives" read the denominator instead of the exponent — provide written feedback: "1/8 means the sample was halved 3 times (1/2 → 1/4 → 1/8), so n = 3." NYSSLS: HS-PS1-8.

**2. Carbon-14 sample after 2 half-lives (half-life = 5,730 years):**

- (a) Fraction remaining: (1/2)² = **1/4**.
- (b) Time elapsed: 2 × 5,730 yr = **11,460 years**.

Step-by-step: After 2 half-lives the sample has been halved twice: 1 → 1/2 → 1/4, so 1/4 remains. Time = number of half-lives × half-life = 2 × 5,730 = 11,460 years.

*Rubric:* 1 point for the correct fraction (1/4); 1 point for the correct time (11,460 years) with the multiplication shown. A student who writes "1/2" applied only one half-life — redirect to the halving ladder. NYSSLS: HS-PS1-8.

**3. Iodine-131 sample after 32 days (half-life = 8 days):**

- (a) Number of half-lives: 32 days ÷ 8 days/half-life = **4 half-lives**.
- (b) Fraction remaining: (1/2)⁴ = **1/16**.

Step-by-step: To find the number of half-lives from a total time, divide: 32 ÷ 8 = 4. Then raise 1/2 to that power: (1/2)⁴ = 1/16. The half-life value comes from Reference Table N (I-131 ≈ 8 days).

*Rubric:* 1 point for dividing correctly to get 4 half-lives; 1 point for the correct fraction (1/16) as (1/2)⁴. A student who multiplied (32 × 8) instead of dividing should be redirected: total time is given, so divide by the half-life to count the half-lives. NYSSLS: HS-PS1-8.

## Exit Ticket Answer

**(a) Phosphorus-32, half-life ≈ 14 days, sample sits 42 days:**

- Number of half-lives: 42 days ÷ 14 days/half-life = **3 half-lives**.
- Fraction remaining: (1/2)³ = **1/8**.

Step-by-step: Divide the total time by the half-life to count the half-lives: 42 ÷ 14 = 3. Then the fraction remaining is (1/2) raised to that number of half-lives: (1/2)³ = 1/8. P-32 is a *different* isotope from the carbon-14 and iodine-131 used in the worksheet practice, so students must apply the method to a new half-life value (14 days) rather than recalling a previous answer.

*Rubric:* 1 point for correctly getting 3 half-lives (42 ÷ 14); 1 point for the fraction 1/8 as (1/2)³. A student who writes "1/3" or "3" for the fraction confused the number of half-lives with the fraction remaining — the number of half-lives is the exponent; the fraction is (1/2) raised to it. NYSSLS: HS-PS1-8.

**(b) Potassium-37, half-life ≈ 1.2 s, after 6 s (about 5 half-lives):**

- Fraction remaining: (1/2)⁵ = **1/32**.

Step-by-step: The problem states this is about 5 half-lives (6 s ÷ 1.2 s = 5). Raise 1/2 to the 5th power: (1/2)⁵ = 1/32. (Accept students who show 6 ÷ 1.2 = 5 explicitly.) This isotope and timescale (seconds) are distinct from the worksheet's years and days, requiring students to apply the same exponent rule in a new context.

*Rubric:* 1 point for recognizing 5 half-lives; 1 point for the fraction 1/32 as (1/2)⁵. A student who writes "1/5" or "1/10" did not raise 1/2 to the 5th power — show the halving ladder out to n = 5 (1/2, 1/4, 1/8, 1/16, 1/32). NYSSLS: HS-PS1-8.

**(c) Why the same fraction decays in each half-life, regardless of starting amount:**

*Full-credit model answer:* In every half-life, exactly one half of whatever atoms are present decay, so the fraction lost (one half) is always the same — a sample of a million atoms loses 500,000 and a sample of 100 atoms loses 50, but both lose the same fraction (1/2), because each individual nucleus has the same fixed probability of decaying in that interval.

*Acceptable variations:* Any response stating that each half-life removes half of *what remains* (not half of the original), and that this fraction (1/2) is fixed and independent of the starting amount, earns full credit. Responses that mention the half-life is a fixed property of the isotope and does not depend on the sample size are also full credit.

*Rubric:* 2 points total — 1 point for stating that exactly one half (the same fraction) decays in each half-life; 1 point for noting this is independent of the starting amount (big and small samples lose the same fraction). Responses that say only "it's always half" without connecting to the starting-amount independence earn 1 point. NYSSLS: HS-PS1-8.

## Closing Reflection (rubric)

The closing reflection is formative, not graded. Award full credit for any genuine, specific response. Look for:

- Any mention of the artifact and how the *fraction remaining* — not how worn or rotted the object looks — is what gives the age. Students who connect the measured fraction to the count of half-lives are showing that the decay clock is real and quantitative, not a guess.
- Responses that use the Because/But/So structure ("...because the half-life is fixed, but we only see the fraction left, so we count the half-lives...") demonstrate the Hochman-style reasoning move from Phase 4. Note these students as having integrated the cause-contrast-consequence logic.
- Students who name a group member who helped them see the (1/2)ⁿ pattern at the whiteboard are signaling that the BTC vertical-surface structure supported their learning — note this as evidence the random-grouping, thinking-classroom structure is working.

If a student's Exit Ticket shows the correct number of half-lives but the wrong fraction (e.g., 3 half-lives but writes "1/3" instead of 1/8), the error is reading the count as the fraction rather than as the exponent on 1/2 — a brief check-in with the halving ladder at the start of the next lesson should resolve it. If a student divides incorrectly (or multiplies instead of dividing) when converting total time to a number of half-lives, reinforce: total time ÷ half-life = number of half-lives before the next lesson builds on radiometric dating.
