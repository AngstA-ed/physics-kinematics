## Make-It-Make-Sense Answers

**1. CuO — oxidation number of copper:**

Oxygen = −2 (Rule 3). CuO is a neutral compound, so the oxidation numbers must add to 0. Therefore Cu + (−2) = 0, which gives **Cu = +2**.

*Rubric:* 1 point for the correct copper value (+2); 1 point for showing the reasoning (oxygen −2 and the sum-to-zero step). A student who writes Cu = −2 has a sign-flip error — provide feedback: "copper must cancel oxygen's −2, so copper is positive, +2." CCC: Patterns / redox-unit foundational.

**2. Cu(OH)₂ — oxidation number of copper:**

Each O = −2 (Rule 3) and each H = +1 (Rule 4). There are two OH groups, contributing 2 × (−2 + 1) = 2 × (−1) = **−2 total**. The compound is neutral, so copper must be **+2** to make the sum zero. Check: (+2) + 2(−2) + 2(+1) = +2 − 4 + 2 = 0. ✓

*Rubric:* 1 point for Cu = +2; 1 point for showing that the two hydroxide groups total −2 and using the sum-to-zero balance. A common error is forgetting the subscript 2 (treating it as one OH, contributing −1, which would give Cu = +1) — note the subscript. CCC: Patterns / redox-unit foundational.

**3. NaCl — oxidation number of sodium and chlorine:**

Na = **+1** (Rule 2, sodium ion is Na⁺). Cl = **−1** (Rule 2, chloride ion is Cl⁻). They add to +1 + (−1) = **0**, which matches a neutral compound. ✓

*Rubric:* 1 point for both ion values correct (+1 and −1); 1 point for noting they sum to 0. Accept the reasoning from ionic charge (Rule 2) or from "oxygen/hydrogen aren't present, so use the known ions." CCC: Patterns / redox-unit foundational.

**4. In 2 Cu + O₂ → 2 CuO, which atom is oxidized and which is reduced:**

**Oxidized: copper** (0 → +2). Copper's oxidation number increases, so copper loses electrons — that is oxidation.
**Reduced: oxygen** (0 → −2). Oxygen's oxidation number decreases, so oxygen gains electrons — that is reduction.

*Rubric:* 2 points total — 1 point for correctly naming copper as oxidized with its 0 → +2 change; 1 point for correctly naming oxygen as reduced with its 0 → −2 change. Partial credit (1 of 2) for identifying the correct number changes but swapping the labels "oxidized"/"reduced." CCC: Patterns / redox-unit foundational.

## Exit Ticket Answer

**(a) Oxidation number of nitrogen in HNO₃:**

- H = +1 (Rule 4).
- Each O = −2 (Rule 3); three oxygens total 3 × (−2) = −6.
- HNO₃ is a neutral compound, so the sum must equal 0: (+1) + N + (−6) = 0.
- Solve: N − 5 = 0, so **N = +5**.

*Rubric:* 1 point for the correct answer (N = +5); 1 point for showing the reasoning (H = +1, O = −2 each / −6 total, sum-to-zero). A student who writes N = +7 likely used +1 for hydrogen but forgot to include it in the balance, or mis-added; a student who writes N = −5 reversed the sign — provide feedback on the balance equation. HNO₃ does not appear in the worksheet practice set, so students must assign it from the rules rather than recall it. CCC: Patterns / redox-unit foundational.

**(b) Oxidation number of sulfur in Na₂SO₄:**

- Each Na = +1 (Rule 2); two sodiums total 2 × (+1) = +2.
- Each O = −2 (Rule 3); four oxygens total 4 × (−2) = −8.
- Na₂SO₄ is a neutral compound, so the sum must equal 0: (+2) + S + (−8) = 0.
- Solve: S − 6 = 0, so **S = +6**.

*Rubric:* 1 point for the correct answer (S = +6); 1 point for showing the reasoning (Na contributes +2 total, O contributes −8 total, sum-to-zero). A student who writes S = +4 likely used only three oxygens or mis-added; a student who forgets to double the sodium will be off — indicate the subscript step. Na₂SO₄ does not appear in the worksheet practice set. CCC: Patterns / redox-unit foundational.

**(c) When iron rusts, is the iron oxidized or reduced?**

*Full-credit model answer:* The iron is **oxidized**, because its oxidation number increases from 0 (free iron metal) to +3 (in Fe³⁺) — an increase in oxidation number means the iron lost electrons, which is the definition of oxidation.

*Acceptable variations:* Any response that states the iron is oxidized AND justifies it by the increase in oxidation number (0 → +3) or by the loss of electrons earns full credit. A response that only says "oxidized" without referencing the number change or electron loss receives partial credit. A response that says "reduced" is incorrect (reduction is a decrease).

*Rubric:* 2 points total — 1 point for "oxidized"; 1 point for justifying with the oxidation-number increase (0 → +3) or electron loss. CCC: Patterns / redox-unit foundational.

## Closing Reflection (rubric)

The closing reflection is formative, not graded. Award full credit for any genuine, specific response. Look for:

- Any mention of the two pennies (bright vs. green) and how the oxidation number (0 vs. +2) connected to a color change they could actually see — students who link the invisible number to the visible patina are showing that the bookkeeping device is real, not abstract.
- Responses that correctly use "oxidized" or "reduced" with a direction ("the number went up, so it's oxidized") are demonstrating the Phase 3 vocabulary integrated into their own words. Note these students as having internalized the pattern.
- Students who name a partner who helped them catch a sign error or a forgotten subscript are signaling that the active-learning paired structure supported their learning — note this as evidence that the assign-before-the-rule design is working.

If a student's Make-It-Make-Sense work shows correct fixed-rule assignments (O = −2, H = +1, ions) but wrong answers on the "solve for the unknown" step, the gap is in the sum-to-overall-charge balance — the single most important procedural step for the rest of the unit. A brief one-on-one check at the start of the next lesson should target that step specifically, since half-reaction balancing depends on it.
