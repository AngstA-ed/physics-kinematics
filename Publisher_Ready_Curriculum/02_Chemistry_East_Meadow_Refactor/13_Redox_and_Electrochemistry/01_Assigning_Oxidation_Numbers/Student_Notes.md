## Guided Notes

**The big idea — Patterns:** Oxidation numbers are not memorized one substance at a time. They follow a short, fixed set of __________. Once you know the rules, you can assign an oxidation number to an atom you have __________ seen before. A __________ in oxidation number across a reaction is the pattern that tells you a redox event happened.

**The five rules for assigning oxidation numbers:**

1. A free element (alone or bonded only to itself) = __________.  *(Cu, O₂, H₂, Na)*
2. A monatomic ion = __________.  *(Na⁺ = +1; Cl⁻ = −1; Cu²⁺ = +2)*
3. Oxygen = __________ in almost every compound.  *(Exception: peroxides like H₂O₂ = −1)*
4. Hydrogen = __________ in almost every compound.  *(Exception: metal hydrides like NaH = −1)*
5. The oxidation numbers in a neutral compound add up to __________; in a polyatomic ion they add up to __________.

**The method (works every time):**

- Step 1: Assign the atoms with __________ rules first (oxygen, hydrogen, the ions).
- Step 2: __________ for the unknown atom using "the sum equals the overall charge."

**Oxidized vs. reduced — the direction of the change:**

| The atom's oxidation number… | The atom… | We say it is… |
|---|---|---|
| goes UP (more positive) | __________ electrons | __________ |
| goes DOWN (more negative) | __________ electrons | __________ |

Oxidation and reduction always happen __________ — electrons lost by one atom are gained by another.

## Worked Example

**Scenario:** A student needs to assign the oxidation number of copper in CuO (the compound that forms as a penny tarnishes).

**Step 1 — Assign the atom you know from a fixed rule:**

Oxygen in a compound = __________ (rule ___). So O = ____.

**Step 2 — Note the overall charge of the formula:**

CuO is a neutral compound, so all oxidation numbers must add up to __________.

**Step 3 — Solve for the unknown atom:**

Cu + (O) = 0  →  Cu + ( ____ ) = 0  →  Cu = ____

**Step 4 — Check against the bright vs. green penny:**

In the bright penny, copper is a free element, so its oxidation number is ____.
In CuO (the green patina), copper is ____.
The change from the bright penny to the green penny is from ____ to ____.

**Step 5 — Name the change:**

Because copper's oxidation number went UP, the copper is __________.

**Step 6 — Because / But / So**

When a penny tarnishes, the copper is oxidized
**because** _______________________________________________,
**but** _______________________________________________,
**so** _______________________________________________.

*Check your reasoning:* "because" should name the electron loss / number increase; "but" should note that it is still the same copper element; "so" should explain why the penny can turn green without anything being added.

## Summary

Complete the sentence:

> The oxidation number of an atom is a __________ label that tracks __________ bookkeeping; you assign it using the __________ (free element = 0, oxygen = −2, hydrogen = +1, and the sum equals the overall charge).

Complete the Because / But / So sentence:

> The copper in a tarnished penny has a higher oxidation number than the copper in a bright penny
> because __________________________________________,
> but __________________________________________,
> so __________________________________________.

**Reminder — the order that works every time:** assign oxygen (−2), hydrogen (+1), and any ions first; then solve for the leftover atom using "the sum equals the overall charge." An atom whose number goes **up** is **oxidized**; an atom whose number goes **down** is **reduced**.
