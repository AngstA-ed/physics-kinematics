## Unit Scope (from East Meadow Scope & Sequence)

This unit teaches the periodic table as a *model* rather than a chart to memorize: a discovered pattern whose lumpy shape, columns, and rows all encode the way electrons arrange themselves around the nucleus. Students begin by rebuilding the table from property cards (Mendeleev's logic), then read electron configurations and valence-electron counts directly off the table, classify elements by their observable property patterns, confront the "same element, different properties" puzzle of allotropes, and finish by predicting periodic trends from a single underlying cause — the pull of the nucleus on the outermost electrons. Throughout, the through-line is HS-PS1-1: *position in the table predicts properties*, because position is a map of electron structure.

| # | Lesson | Core idea |
|---|---|---|
| 01 | Placement of Elements | The table's shape encodes electron arrangement; periods are rows, groups are columns, position predicts properties |
| 02 | Electron Configuration & Valence Electrons | Read an electron configuration off Reference Table S; the last number is the valence count that drives chemistry |
| 03 | Classes of Elements | Sort elements into metals, nonmetals, and metalloids by repeating property and reactivity patterns |
| 04 | Allotropes | Same element, different structure → different properties (diamond vs. graphite); structure determines function |
| 05 | Periodic Trends | Atomic radius, ionization energy, electronegativity, and metallic character all trace to nuclear pull + distance |

## Pacing Calendar

| Day | Lesson | Phenomenon anchor | Strategy |
|---|---|---|---|
| 1 | 01 Placement of Elements | A blank periodic table's strange, lumpy staircase shape — why draw it that way on purpose? | Restorative Circle (unit opener) |
| 2 | 02 Electron Configuration & Valence Electrons | Li, Na, K react with water the same way, more violently down the column — what's the same about them? | Hochman |
| 3 | 03 Classes of Elements | Copper rings, bends, and lights a bulb; sulfur is dull, brittle, and an insulator — same shelf, opposite behavior | BTC |
| 4 | 04 Allotropes | Diamond scratches glass; pencil graphite smears on paper — both are pure carbon | Active Learning |
| 5 | 05 Periodic Trends | Francium would react far more violently with water than sodium — why, down the same group? | Hochman |

Double-period days (every other day) let the card-sort discovery (Lesson 01) and the property-classification investigation (Lesson 03) run long.

## Strategy Rotation

- **RESTORATIVE CIRCLE**: Lesson 01 (unit-opening circle — sorting a big pile, surfacing the intuition that organization follows a rule).
- **ACTIVE LEARNING**: Lessons 01, 04 (Mendeleev card-sort re-enactment; build-then-explain diamond/graphite modeling).
- **BTC (Building Thinking Classrooms)**: Lesson 03 (visibly random groups + vertical surfaces for the thin-sliced metal/nonmetal/metalloid sort).
- **HOCHMAN (literacy)**: Lessons 02, 05 (appositive sentences defining valence electrons; appositives that carry a trend's definition and cause in one sentence).

SEL (opening connection + closing reflection), ELL/SPED supports, OPTIC/CER literacy, and a Curated Resources block appear in every lesson.
