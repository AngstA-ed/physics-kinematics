## Guided Notes

**The big idea — Patterns:** The periodic table is not a random grid. It is a __________ that repeats. Elements are placed in order of increasing __________ __________ (the number of protons). Because outer-electron arrangement repeats, an element's __________ in the table predicts its chemistry.

**Two directions on the table:**

| Direction | Name | What the number tells you |
|---|---|---|
| Horizontal **row** | __________ | the number of electron __________ (shells) the atom fills |
| Vertical **column** | __________ | the number of __________ electrons (for main-group elements) |

**The key rule of placement:**

Elements are arranged in order of increasing __________ __________ — that is, by how many __________ are in the nucleus. (Not by mass — atomic number is the true ordering principle.)

**Valence electrons — the electrons that matter for chemistry:**

- Valence electrons are the electrons in the __________ energy level (the outer ring of a Bohr model).
- Sodium has 11 electrons total, but only ________ valence electron.
- It is the __________ electrons, not the total count, that decide how an atom bonds and reacts.

## Worked Example

**Scenario:** Describe the placement of **magnesium (Mg)** and use it to predict its chemistry.

**Step 1 — Find it on the Periodic Table.** Magnesium has atomic number 12, so it has ________ protons.

**Step 2 — Read its period (row):** Magnesium is in Period ________. This tells me its electrons fill ________ energy levels (shells).

**Step 3 — Read its group (column):** Magnesium is in Group ________. For a main-group element, this tells me it has ________ valence electrons.

**Step 4 — Build the Bohr-model picture:** Shells of magnesium: 2, ________, ________ (innermost first). The outer shell holds ________ electron(s) — the valence electrons.

**Step 5 — Predict the chemistry:** Because magnesium has the same number of valence electrons as ________ (another Group 2 element, such as Be or Ca), it should react in a __________ way.

**Step 6 — Because / But / So**

Magnesium reacts similarly to the other elements in its column
**because** _______________________________________________,
**but** _______________________________________________,
**so** _______________________________________________.

*Check your reasoning:* "because" should name the shared valence electrons / same group; "but" should note what differs (period / number of shells / size); "so" should state that the chemistry matches even though the size differs.

## Summary

Complete the sentence:

> An element's **position** in the periodic table tells you its chemistry: the __________ (row) gives the number of electron shells, and the __________ (column) gives the number of __________ electrons.

Complete the Because / But / So sentence:

> The periodic table has its strange, lumpy shape
> because __________________________________________,
> but __________________________________________,
> so __________________________________________.

**Reminder:** Same **group** = same number of **valence electrons** = similar chemistry. Same **period** = same number of electron shells. Elements are placed in order of increasing **atomic number** (protons).

**Key reference (from the 2025 NYS Reference Tables):**
Atomic number = number of protons (Periodic Table). Main-group number = number of valence electrons.
