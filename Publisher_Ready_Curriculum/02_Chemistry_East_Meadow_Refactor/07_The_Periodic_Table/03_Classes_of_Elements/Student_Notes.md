## Worked Example

**Scenario:** A new element, **"Element M,"** is tested. It is shiny, it lights the conductivity bulb brightly, and it flattens under a gentle mallet tap instead of shattering. Classify it and predict its behavior.

**Step 1 — Record the three property observations:**

- Luster: ___________
- Conductivity: ___________
- Mallet test: ___________

**Step 2 — Match the observations to a property cluster:**

Shiny + conducts well + flattens (malleable) → this matches the __________ cluster.

**Step 3 — Classify:**

Element M is a ___________.

**Step 4 — Predict using the Patterns CCC:**

Because Element M fits the metal pattern, I predict it would __________ electricity in a circuit and, when it reacts, would tend to __________ electrons.

**Step 5 — Because / But / So**

Element M is classified as a metal
**because** _______________________________________________,
**but** _______________________________________________,
**so** _______________________________________________.

*Check your reasoning:* "because" should name the metal property cluster; "but" should contrast it with what a nonmetal would have shown; "so" should state the classification and one prediction.

## Summary

Complete the Because / But / So sentence:

> We can predict an element's class before testing it
> because __________________________________________,
> but __________________________________________,
> so __________________________________________.

**Reminder:** Classify by the *cluster* of properties — luster **and** conductivity **and** the mallet test — not by a single observation. A metalloid is the "third pile": in-between, partly shiny, only weakly conductive, and brittle.

**Key idea (no group names needed):** Metals, nonmetals, and metalloids are defined by what they *do* — their physical-property pattern and their tendency to react — not by where they sit by name on the table.
