# Classes of Elements — Answer Key

## Cover

Unit: The Periodic Table — Lesson 03: Classes of Elements
East Meadow Schools × Valley Stream Central High School District
NYSSLS tag: HS-PS1-1 (applied) — classify elements by physical-property patterns (metal / nonmetal / metalloid); connect property cluster to reactivity. No group-name memorization.

## Make-It-Make-Sense Answers

**1. Element A** (shiny, bends flat under a hammer, lights the bulb brightly):

- **Classification:** metal.
- **Property evidence:** any two of — luster (shiny), malleability (bends/flattens instead of shattering), high electrical conductivity (lights the bulb brightly).
- **Prediction:** it conducts electricity well in a circuit, and when it reacts it tends to *lose* electrons. · *Rubric:* full credit for "metal" + two correct property reasons + a behavior prediction consistent with the metal cluster. Partial credit for the correct class with only one property reason. NYSSLS: HS-PS1-1 (applied).

**2. Element B** (dull, shatters when tapped, does not light the bulb):

- **Classification:** nonmetal.
- **Property evidence:** any two of — no luster (dull), brittleness (shatters instead of bending), poor/no conductivity (does not light the bulb / insulator).
- **Prediction:** it acts as an insulator in a circuit (will not carry current), and when it reacts it tends to *gain or share* electrons. · *Rubric:* full credit for "nonmetal" + two correct property reasons + a consistent prediction; "metalloid" is incorrect here because all three properties point clearly to the nonmetal cluster (no in-between behavior). NYSSLS: HS-PS1-1 (applied).

**3. Element C** (slight shine, brittle, lights the bulb only very dimly):

- **Classification:** metalloid.
- **Why it fits neither pile cleanly:** it has *some* luster (a metal trait) but is brittle (a nonmetal trait) and conducts only weakly — partial/"semi" conductivity, which is neither the strong conduction of a metal nor the insulating behavior of a nonmetal. The mixed cluster is the signature of a metalloid.
- **Real-world use:** semiconductor applications (e.g., silicon in computer chips / solar cells), where partial conductivity is exactly the useful property. · *Rubric:* full credit for "metalloid" + an explanation that names at least one metal-like AND one nonmetal-like property (showing the mix). Partial credit for "metalloid" with only a vague "it's in between." NYSSLS: HS-PS1-1 (applied).

## Exit Ticket Answer

**(a) Classification of Element Z** (dull, grayish, shatters when tapped, does not light the bulb):

**Nonmetal.**

**(b) Two supporting property observations** (any two of the following):

- Dull / no luster.
- Brittle — shatters into pieces when tapped (does not bend or flatten).
- Does not conduct electricity — fails to light the bulb (acts as an insulator).

**(c) Prediction + reasoning (sample full-credit response):**

> *"Element Z fits the nonmetal pattern — dull, brittle, and an insulator — so I predict it will not carry current in a circuit, and when it reacts it will tend to gain or share electrons rather than lose them. Once an element matches the nonmetal property pattern, its behavior is predictable, which is why classifying it is useful."*

Any equivalent response that (i) makes a behavior prediction consistent with the nonmetal class — insulator in a circuit, or gains/shares electrons when reacting — and (ii) explains that the *pattern* of properties allows the prediction, earns full credit.

*Tolerance/rubric:* (a) 1 point for "nonmetal." (b) 1 point for each correct property observation, 2 points total; partial credit (1 point) for one correct observation. (c) 2 points — 1 point for a behavior prediction consistent with the nonmetal class, 1 point for explaining that the property *pattern* makes the prediction possible (Patterns CCC). **Element Z was not one of the lab samples** — full credit requires the student to apply the pattern to a new case, not recall a tested result. NYSSLS: HS-PS1-1 (applied).

## Closing Reflection (rubric)

The closing reflection is formative, not graded. Award full credit for any genuine, specific response. Look for:

- A specific *first property to look for* — "I'll check if it conducts electricity first" or "I'll do the mallet test to see if it bends or shatters" — rather than a generic "I'll look at it." Naming a particular test signals the student internalized the property-cluster approach.
- Naming a group member who helped catch a sorting decision (especially on the in-between/metalloid sample) — this signals the BTC collaborative structure landed and that the student valued peer reasoning at the vertical surface.
- Any response that connects classification to prediction ("now I can guess how a new element acts") shows the strongest transfer of the Patterns CCC.

If a student's Exit Ticket forces Element Z into a metal-vs-nonmetal binary but otherwise reasons well, the classification skill is solid — the brief check-in to add is the *third class* (metalloid) and the idea that some elements are genuinely in-between. If a student classifies Element Z as a metal despite "dull, brittle, does not conduct," the issue is reading the property cluster as a whole — revisit that all three observations must point the same way, and that a single trait is not enough to classify.
