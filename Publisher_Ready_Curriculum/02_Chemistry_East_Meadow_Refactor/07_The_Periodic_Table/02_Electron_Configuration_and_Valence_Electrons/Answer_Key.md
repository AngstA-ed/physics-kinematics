## Make-It-Make-Sense Answers

**1. Lithium (Li):**

- Electron configuration: **2-1**
- Number of valence electrons: **1** (the last number of the configuration)
- Group: **1**

Step-by-step: lithium's configuration on Reference Table S is 2-1; the outermost shell (the last number) holds 1 electron, so lithium has 1 valence electron, placing it in Group 1. · *Rubric:* 1 point for the correct configuration (2-1); 1 point for identifying 1 valence electron AND Group 1. A student who writes "3 valence electrons" likely counted total electrons (2 + 1) instead of the outermost shell — provide feedback: valence electrons = the last number only. NYSSLS: HS-PS1-1.

**2. Chlorine (Cl):**

- Electron configuration: **2-8-7**
- Number of valence electrons: **7** (the last number)
- Group: **17**

Step-by-step: chlorine's configuration is 2-8-7; the outermost shell holds 7 electrons, so chlorine has 7 valence electrons and is in Group 17 (the group number ends in the digit 7). · *Rubric:* 1 point for the configuration (2-8-7); 1 point for 7 valence electrons AND Group 17. A common error is to give "17 valence electrons" (the total) — redirect to the last-number rule. NYSSLS: HS-PS1-1.

**3. Argon (Ar):**

- Electron configuration: **2-8-8**
- Number of valence electrons: **8** (the last number)
- Group: **18**
- Why is argon so unreactive? Argon's outermost shell already holds a full set of 8 electrons. It has no loose outer electron to give away and no room to gain one, so it does not need to react with other atoms — this is the noble-gas pattern.

Step-by-step: argon's configuration is 2-8-8; the outer shell is full at 8, so argon has 8 valence electrons and sits in Group 18. · *Rubric:* 1 point for configuration (2-8-8) and 8 valence electrons / Group 18; 1 point for explaining unreactivity in terms of a *full* outer shell. NYSSLS: HS-PS1-1.

## Exit Ticket Answer

**(a) Magnesium (Mg):**

- Electron configuration: **2-8-2**
- Valence electrons: **2** (the last number)
- Group: **2**

Magnesium's configuration on Reference Table S is 2-8-2; the outermost shell holds 2 electrons, so magnesium has 2 valence electrons and is in Group 2. Magnesium is deliberately *not* one of the worksheet practice elements, so students must transfer the method rather than recall an answer.

*Rubric:* 1 point for the correct configuration (2-8-2); 1 point for 2 valence electrons AND Group 2. A student who writes "12 valence electrons" counted total electrons — note the last-number rule. NYSSLS: HS-PS1-1.

**(b) Fluorine (F):**

- Electron configuration: **2-7**
- Valence electrons: **7** (the last number)
- Group: **17**

Fluorine's configuration is 2-7; the outermost shell holds 7 electrons, so fluorine has 7 valence electrons and is in Group 17 — the same group as chlorine, which is why the two behave alike. Fluorine has only two shells (period 2), while chlorine has three (period 3), but they share the valence count.

*Rubric:* 1 point for the configuration (2-7); 1 point for 7 valence electrons AND Group 17. Accept a student who notes fluorine is in the same group as chlorine as a bonus connection. NYSSLS: HS-PS1-1.

**(c) Why all Group 17 elements are highly reactive:**

*Full-credit model answer:* Every Group 17 element has 7 valence electrons — one short of a full outer shell of 8 — so each one strongly tends to gain a single electron to complete its shell, which makes the whole group highly reactive.

*Acceptable variations:* Any response that identifies the shared count of 7 valence electrons (one short of a full shell) as the reason, and connects it to the tendency to gain an electron, earns full credit. Responses that say only "they are in the same group" without naming the 7-valence-electron / one-short-of-full reasoning should receive partial credit.

*Rubric:* 2 points total — 1 point for identifying 7 valence electrons (one short of a full shell of 8) as the shared feature; 1 point for connecting that count to the tendency to gain one electron and therefore react readily. NYSSLS: HS-PS1-1.

## Closing Reflection (rubric)

The closing reflection is formative, not graded. Award full credit for any genuine, specific response. Look for:

- Any mention of how a single number (the last number of the configuration, or the group number) predicted an element's behavior — students who name this connection are showing that the pattern, not memorization, is what carried the learning.
- Responses that use the appositive structure ("valence electrons — the outermost electrons — determine how an element reacts") are demonstrating the Hochman writing move from Phase 3 and Phase 4. Note these students as having integrated the vocabulary into their active sentence structure.
- Students who name a partner who helped them catch an error (for example, mixing up the period number with the valence count) are signaling that the station and partner structure supported their learning — note this as evidence that the collaborative format is working.

If a student's Exit Ticket shows the correct configuration but the wrong valence count (for example, giving the total electron count or the number of shells), the error is in reading the *last number* — a brief one-on-one check at the start of the next lesson should resolve it before Lewis structures and ion formation build on this skill. If the configuration itself is wrong, the student needs practice locating values on Reference Table S before the next lesson.
