## Worked Example

**Scenario:** A student needs to find the valence electrons and group of sulfur (S).

**Step 1 — Look up the electron configuration on Reference Table S:**

Sulfur (S) configuration: ___________

**Step 2 — Count the shells (rings):**

Number of numbers in the configuration = number of shells = ___

**Step 3 — Find the valence electrons (the last number):**

Valence electrons = ___

**Step 4 — Use the rule to find the group:**

Valence electrons = ___  →  for Groups 13–18 the group number ends in that digit  →  Group ___

**Step 5 — Appositive sentence:**

Sulfur's valence electrons — its ___ outermost electrons — make it a reactive nonmetal that tends to ___ electrons to fill its shell.

**Step 6 — Because / But / So**

Sulfur and oxygen react in similar ways
**because** _______________________________________________,
**but** _______________________________________________,
**so** _______________________________________________.

*Check your reasoning:* "because" should name the shared valence count; "but" should acknowledge what is different (mass, number of shells); "so" should state why the behavior is still similar (same group).

> All of the Group 1 metals react with water in the same way

**Reminder:** The **last number** of an electron configuration is the number of valence electrons. The number of separate numbers tells you how many shells (and which period the element is in). Group number predicts valence electrons for the main-group elements.

**Key reference (from the 2025 NYS Reference Tables):**
Electron configurations: printed under each symbol on the Periodic Table (Reference Table S)
First shell holds up to 2 electrons; second and third shells hold up to 8.
