## Guided Notes

**The big idea — Patterns:** The number of valence electrons follows a pattern: for a main-group atom it equals the __________ number. Because the pattern is reliable, a single dot diagram lets you __________ how an atom will bond before any reaction is run.

**How to draw a Lewis dot diagram:**

1. Write the element __________ in the center.
2. Find the atom's __________ number from the Periodic Table — this equals the number of valence electrons.
3. Place the dots one per __________ (top, bottom, left, right) before doubling up.
4. The dots show only the __________ electrons (the outermost shell), not all the atom's electrons.

**The octet rule:** Atoms gain, lose, or share electrons until they are surrounded by __________ valence electrons — a full outer shell, the stable arrangement of the noble gases. The one exception is __________ (and helium), which is full at __________ electrons.

**Predicting bonds from the dots:** An atom that is far from eight bonds __________; an atom that already has eight (a noble gas) __________ bond. Count how many electrons an atom is short of eight, and you can predict how many bonds it forms.

**Reminder:** For a main-group atom, the number of valence electrons equals the **group number**. Draw dots one per side before pairing — the unpaired dots are the electrons available to bond. Hydrogen is the exception to "eight": its shell is full at **two**.

Group number → valence electrons (Periodic Table)
