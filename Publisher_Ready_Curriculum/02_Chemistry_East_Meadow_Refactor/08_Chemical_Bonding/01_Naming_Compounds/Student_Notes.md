## Guided Notes

**The big idea — Patterns:** Naming feels complicated only until you see it is __________ small rule sets, and one question routes every formula to exactly one of them. That first question is always: *what kinds of __________ are present?*

**The one routing question — fill in each branch:**

| What kinds of elements? | Type of compound | How you name it |
|---|---|---|
| Metal + nonmetal (single anion) | binary ionic | cation name + anion root + __________ |
| Metal + polyatomic ion | ternary ionic | cation name + the polyatomic ion's __________ name (kept whole) |
| Two nonmetals | covalent | __________ prefixes on both elements |
| Begins with H, dissolved in water | acid | the __________ rules |

**Greek prefixes for covalent compounds (fill in the count):**

| Prefix | mono- | di- | tri- | tetra- | penta- |
|---|---|---|---|---|---|
| Number | ___ | ___ | ___ | ___ | ___ |

> Special rule: you **drop the prefix __________** on the very first element. CO is "carbon monoxide," not "monocarbon monoxide."

**The acid rules (fill in the ending):**

- Anion ends in **-ide** (e.g., chloride) → name the acid **hydro-…-__________ acid**  → HCl(aq) = __________ acid
- Polyatomic ion ends in **-ate** (e.g., sulfate) → name the acid **-__________ acid**  → H₂SO₄(aq) = __________ acid
- Polyatomic ion ends in **-ite** (e.g., sulfite) → name the acid **-__________ acid**  → H₂SO₃(aq) = __________ acid

**Quick rule recall:**

- Ionic: never use Greek prefixes; the charges set the ratio.
- Polyatomic ion: look it up on **Table E** and keep its name whole.
- Covalent: Greek prefixes on both elements; drop *mono-* on the first.
- Acid: -ide → *hydro-…-ic*; -ate → *-ic*; -ite → *-ous*.
