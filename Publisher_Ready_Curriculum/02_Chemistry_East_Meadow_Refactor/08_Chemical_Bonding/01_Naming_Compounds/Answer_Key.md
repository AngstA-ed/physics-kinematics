# Naming Compounds — Answer Key

## Make-It-Make-Sense Answers

**1. MgO — magnesium oxide**

- Kinds of elements: metal (Mg) + nonmetal (O). Branch: **binary ionic**.
- Rule applied: cation name (magnesium) + anion root with **-ide** ending (oxygen → ox**ide**). No prefixes (ionic). Mg²⁺ and O²⁻ balance 1:1, so the formula is MgO.
- **Name: magnesium oxide.**

*Rubric:* 1 point for the correct name; 1 point for identifying the binary-ionic branch and the "-ide" rule. A student who writes "magnesium dioxide" applied a covalent prefix to an ionic compound — flag the misconception (prefixes are covalent-only). NYSSLS: supports HS-PS1-1 / HS-PS1-2.

**2. Ca(NO₃)₂ — calcium nitrate**

- Kinds of elements: metal (Ca) + polyatomic ion (NO₃⁻). Branch: **ternary (polyatomic) ionic**.
- Polyatomic ion present (Table E): **nitrate**, NO₃⁻. Kept whole — no "-ide," no prefix. The subscript 2 outside the parentheses balances Ca²⁺ with two nitrate ions, but that count does **not** appear in the name.
- **Name: calcium nitrate.**

*Rubric:* 1 point for the correct name; 1 point for naming the polyatomic ion (nitrate) and stating it is kept whole. Common error: "calcium nitride" (nitride = N³⁻, a different, monatomic anion). If this appears, contrast nitrate (NO₃⁻, polyatomic) with nitride (N³⁻, monatomic). NYSSLS: supports HS-PS1-1 / HS-PS1-2.

**3. N₂O₄ — dinitrogen tetroxide**

- Kinds of elements: two nonmetals (N and O). Branch: **covalent**.
- Prefixes: nitrogen appears twice → **di**nitrogen; oxygen appears four times → **tetr(a)**oxide (the *a* drops before the vowel *o*). The first element keeps its prefix here because there are two nitrogens.
- **Name: dinitrogen tetroxide** (accept "dinitrogen tetraoxide").

*Rubric:* 1 point for the correct name; 1 point for showing both prefixes (di- for 2 N, tetra-/tetr- for 4 O). A student who writes "nitrogen oxide" omitted the counting prefixes — the whole point of covalent naming. Provide feedback that covalent compounds must count atoms with prefixes. NYSSLS: supports HS-PS1-1 / HS-PS1-2.

**4. HNO₃(aq) — nitric acid**

- Kinds of elements: H + polyatomic ion (NO₃⁻), dissolved in water. Branch: **acid (oxyacid)**.
- Polyatomic ion: **nitrate** (NO₃⁻), which ends in **-ate**. The acid rule for an *-ate* ion is **-ic acid**: nitr**ate** → nitr**ic** acid. (No "hydro-" because it is an oxyacid, not a binary acid.)
- **Name: nitric acid.**

*Rubric:* 1 point for the correct name; 1 point for identifying the -ate → -ic acid rule (and not adding "hydro-"). A student who writes "hydronitric acid" applied the binary-acid rule to an oxyacid — clarify that "hydro-" is only for binary acids (H + one nonmetal). NYSSLS: supports HS-PS1-1 / HS-PS1-2.

## Exit Ticket Answer

**(a) Li₂O — lithium oxide**

Binary ionic (metal + nonmetal). Cation name (lithium) + oxygen with **-ide** ending → lithium oxide. Li⁺ and O²⁻ balance 2:1, giving Li₂O; no prefix appears in the name (ionic).

*Rubric:* 1 point for the correct name; 1 point for the binary-ionic branch + "-ide" rule. Reject "dilithium oxide" (prefixes are covalent-only). NYSSLS: supports HS-PS1-1 / HS-PS1-2.

**(b) K₂CO₃ — potassium carbonate**

Ternary (polyatomic) ionic. Cation name (potassium) + the polyatomic ion **carbonate** (CO₃²⁻, Table E), kept whole. K⁺ and CO₃²⁻ balance 2:1; that count does not appear in the name.

*Rubric:* 1 point for the correct name; 1 point for naming the polyatomic ion (carbonate) and keeping it whole. Reject "potassium carbide" (carbide = C, monatomic) and "potassium tricarbonate" (no prefixes on ionic). NYSSLS: supports HS-PS1-1 / HS-PS1-2.

**(c) SF₆ — sulfur hexafluoride**

Covalent (two nonmetals). Sulfur appears once → no prefix on the first element (drop *mono-*); fluorine appears six times → **hexa**fluoride. 

*Rubric:* 1 point for the correct name; 1 point for the hexa- prefix on fluorine and correctly dropping the prefix on the single sulfur. A student who writes "monosulfur hexafluoride" did not drop *mono-* on the first element — note the rule. NYSSLS: supports HS-PS1-1 / HS-PS1-2.

**(d) HF(aq) — hydrofluoric acid**

Binary acid (H + one nonmetal, fluorine, dissolved in water). Fluorine → fluoride ends in **-ide**, so the binary-acid rule applies: **hydro-** + fluor + **-ic acid** → hydrofluoric acid.

*Rubric:* 1 point for the correct name; 1 point for applying the binary-acid rule (hydro-…-ic) and not the oxyacid rule. A student who writes "hydrogen fluoride" named the gas, not the aqueous acid — clarify that the (aq) signals the acid name. NYSSLS: supports HS-PS1-1 / HS-PS1-2.

**(e) Why a precise naming system matters (uses *pattern* and *atoms*):**

*Full-credit model answer:* A precise naming system follows a fixed **pattern** that encodes exactly which **atoms** are present and how many, so two substances that look almost the same — like CO and CO₂ — can never be confused, because their names differ in a way that always maps back to the actual atoms.

*Acceptable variations:* Any response that (i) uses the words *pattern* and *atoms*, and (ii) connects the precise name to telling substances apart / preventing dangerous confusion, earns full credit. A response that uses the two words but only restates "naming is important" without the prevent-confusion idea earns partial credit.

*Rubric:* 2 points total — 1 point for correctly naming three of the four compounds in (a)–(d); 1 point for an (e) sentence that uses both required words and explains that the pattern maps a name to specific atoms/counts so substances are not confused. NYSSLS: supports HS-PS1-1 / HS-PS1-2.

## Closing Reflection (rubric)

The closing reflection is formative, not graded. Award full credit for any genuine, specific response. Look for:

- A specific "click" moment from the card game or flow-chart — e.g., "It clicked when I saw that only the two-nonmetal pile had 'di-' and 'tetra-' in the names" — rather than a generic "it made sense." Students who can point to the inductive moment have internalized the *pattern*, not just memorized rules.
- Naming a tablemate who helped — "Marcus caught that I left a charge on CaCl, so we added a second chlorine" — signals that the ACTIVE LEARNING card structure supported collaboration. Note these students as evidence the group format is working.
- Any response that links a naming rule back to the opening phenomenon (a small name difference flipping a poison to a safe substance) shows the strongest transfer of the Patterns CCC.

If a student's Exit Ticket shows correct branch choices but wrong endings (e.g., "lithium oxite" or "carbon dioxite"), the error is in the suffix rules, not the routing — a brief one-on-one on the -ide / -ate / -ite endings at the start of the next lesson should be sufficient. If a student applied Greek prefixes to an ionic compound (e.g., "dilithium oxide"), reteach the ionic-vs-covalent prefix distinction before the next lesson builds on these names.
