## Worked Example

**Scenario:** A Regents item gives you **88 g of carbon dioxide (CO₂)** and asks for the number of moles. This is a *mole-conversion* pattern.

**Step 1 — Name the type:** It gives grams and asks for moles → use moles = mass ÷ gram formula mass (Table T).

**Step 2 — Find the gram formula mass of CO₂ (Periodic Table):**

| Element | Atomic mass (g/mol) | Subscript | Mass contribution |
|---|---|---|---|
| C | ___ | 1 | ___ |
| O | ___ | 2 | ___ |
| **GFM** | | | **___ g/mol** |

**Step 3 — Set up using the Table T formula:**

> moles = mass ÷ GFM = 88 g ÷ ________ g/mol = ________ mol

**Step 4 — Check the answer is reasonable:** 88 g is twice the GFM (44 g/mol), so the answer should be about __________ moles.

**Step 5 — Because / But / So:**

A student who writes only the final number "2.0 mol" on a constructed response may lose points
**because** _______________________________________________,
**but** _______________________________________________,
**so** _______________________________________________.

*Check your reasoning:* "because" should name what constructed-response items reward; "but" should name what the student left out; "so" should state what to always show.

**Reminder — the two threads of the whole course:**
**Matter** is classified, built from atoms, and bonded. **Energy** drives every change matter undergoes — melting, dissolving, reacting. Every unit is one of those two threads.

**Key reference (from the 2025 NYS Reference Tables):**
- Table S — densities and physical properties (e.g., aluminum = 2.70 g/cm³)
- Table F — solubility guidelines (e.g., AgCl is insoluble; most nitrates are soluble)
- Table T — important formulas (e.g., number of moles = given mass ÷ gram-formula-mass)
