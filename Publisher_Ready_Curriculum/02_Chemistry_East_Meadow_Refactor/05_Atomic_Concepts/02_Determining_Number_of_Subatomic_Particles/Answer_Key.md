## Make-It-Make-Sense Answers

**1. ³⁹K (potassium-39, neutral):**

| Quantity | How to find it | Value |
|---|---|---|
| Protons | = atomic number (Z) | 19 |
| Neutrons | = mass number − atomic number (39 − 19) | 20 |
| Electrons | = protons (neutral) | 19 |

Step-by-step: potassium's atomic number is 19, so there are 19 protons. Neutrons = 39 − 19 = 20. A neutral atom has electrons equal to protons, so 19 electrons.

*Rubric:* 1 point for 19 protons (read directly from Z); 1 point for showing the neutron subtraction 39 − 19 = 20 and 19 electrons. A student who writes "39 neutrons" used the mass number directly — provide feedback: "the mass number counts protons AND neutrons; subtract the 19 protons to get the neutrons." NYSSLS: HS-PS1-1.

**2. ²⁴Mg²⁺ (magnesium-24 ion, charge +2):**

| Quantity | How to find it | Value |
|---|---|---|
| Protons | = atomic number (Z) | 12 |
| Neutrons | = mass number − atomic number (24 − 12) | 12 |
| Electrons | = protons − charge (12 − 2) | 10 |

Step-by-step: magnesium's atomic number is 12, so 12 protons. Neutrons = 24 − 12 = 12. The +2 charge means the atom lost 2 electrons, so electrons = 12 − 2 = 10. The protons and neutrons are unchanged by ionization — it is still magnesium.

*Rubric:* 1 point for 12 protons and 12 neutrons; 1 point for 10 electrons with the protons − charge reasoning shown. A common error is electrons = 12 + 2 = 14 — note that a *positive* charge means electrons were *lost*, so subtract. NYSSLS: HS-PS1-1.

**3. ³⁵Cl⁻ (chloride ion, charge −1):**

| Quantity | How to find it | Value |
|---|---|---|
| Protons | = atomic number (Z) | 17 |
| Neutrons | = mass number − atomic number (35 − 17) | 18 |
| Electrons | = protons − charge (17 − (−1)) | 18 |

Step-by-step: chlorine's atomic number is 17, so 17 protons. Neutrons = 35 − 17 = 18. The −1 charge means the atom gained 1 electron; electrons = protons − charge = 17 − (−1) = 17 + 1 = 18.

*Rubric:* 1 point for 17 protons and 18 neutrons; 1 point for 18 electrons with the subtract-a-negative reasoning shown (17 − (−1) = 18). A student who writes 16 electrons subtracted the magnitude in the wrong direction — note that a *negative* charge means electrons were *gained*. NYSSLS: HS-PS1-1.

**Identity pattern (the "Make It Make Sense" point):** Across all three species, the proton count came directly from the atomic number and stayed equal to it every time — even when the neutron count differed (isotopes) or the electron count differed (ions). Only the proton count is fixed for a given element. *Rubric:* full credit for any answer naming protons (the atomic number) as the quantity that always equals Z and defines the element. NYSSLS: HS-PS1-1.

## Exit Ticket Answer

**(a) ¹⁸O (oxygen-18, neutral):**

| Quantity | How to find it | Value |
|---|---|---|
| Protons | = atomic number (Z) | 8 |
| Neutrons | = mass number − atomic number (18 − 8) | 10 |
| Electrons | = protons (neutral) | 8 |

Oxygen's atomic number is 8, so 8 protons. Neutrons = 18 − 8 = 10. Neutral atom, so 8 electrons. (¹⁸O is a different isotope from the more common ¹⁶O — same 8 protons, more neutrons.)

*Rubric:* 1 point for 8 protons and 8 electrons; 1 point for showing the neutron subtraction 18 − 8 = 10. A student who writes "18 neutrons" missed the subtraction — provide written feedback on A − Z. NYSSLS: HS-PS1-1.

**(b) Al³⁺ (aluminum ion, mass number 27, charge +3):**

| Quantity | How to find it | Value |
|---|---|---|
| Protons | = atomic number (Z) | 13 |
| Neutrons | = mass number − atomic number (27 − 13) | 14 |
| Electrons | = protons − charge (13 − 3) | 10 |

Aluminum's atomic number is 13, so 13 protons. Neutrons = 27 − 13 = 14. The +3 charge means the atom lost 3 electrons; electrons = 13 − 3 = 10.

*Rubric:* 1 point for 13 protons and 14 neutrons; 1 point for 10 electrons with the protons − charge reasoning. A student who writes 16 electrons added the charge instead of subtracting — note that the +3 means three electrons were lost. NYSSLS: HS-PS1-1.

**(c) Why adding one proton to a fluorine atom changes the element:**

*Full-credit model answer:* Fluorine has 9 protons (atomic number 9), and the number of protons is what defines the element; adding one proton raises the count to 10, which is the atomic number of neon — so the atom is no longer fluorine, it has become a different element entirely.

*Acceptable variations:* Any response that states (1) the proton count / atomic number defines the element and (2) changing the proton count (from 9 to 10) therefore changes which element it is, earns full credit. Naming the new element (neon, Z = 10) is a bonus but not required. Responses that say only "it changes" without explaining that protons define identity should receive partial credit.

*Rubric:* 2 points total — 1 point for identifying the proton count (atomic number) as what defines the element; 1 point for connecting the change in proton count (9 → 10) to a change in element identity. NYSSLS: HS-PS1-1.

## Closing Reflection (rubric)

The closing reflection is formative, not graded. Award full credit for any genuine, specific response. Look for:

- Any mention of the *Build an Atom* simulation moment when adding a proton switched the element name — students who connect the on-screen change to the identity rule are showing the phenomenon landed, not just the procedure.
- Responses that use the appositive structure ("the atomic number — the number of protons — defines the element") are demonstrating the Hochman writing move from Phase 3 and Phase 4. Note these students as having integrated the vocabulary into their active sentence structure.
- Students who name a partner who helped them catch a counting error (a neutron subtraction missed, or an ion charge added instead of subtracted) are signaling that the group investigation structure supported their learning — note this as evidence that the collaborative table format is working.

If a student's Exit Ticket shows correct atomic numbers but the neutron count equals the mass number (e.g., "18 neutrons" for ¹⁸O), the error is in skipping the A − Z subtraction — a brief check-in at the start of the next lesson should be sufficient. If a student consistently adds the charge to the electrons rather than subtracting it, reteach the ion rule (electrons = protons − charge; positive charge means electrons lost) before the next lesson builds on ion formation.
