## Guided Notes

**The big idea — Stability and Change:** The number of __________ in an atom never changes for a given element — that is the atom's stable *identity* (its atomic number). What can change is the number of __________, which changes the atom's __________ number and, for some atoms, the __________ of the nucleus.

**What makes two atoms isotopes?**

| Feature | Carbon-12 | Carbon-14 | Same or different? |
|---|---|---|---|
| Protons | 6 | 6 | |
| Electrons | 6 | 6 | |
| Neutrons | 6 | 8 | |
| Mass number | 12 | 14 | |

So: isotopes have the **same** number of __________ (so they are the same element) but a **different** number of __________ (so they have different mass).

**The two carbon isotopes that matter for dating:**

![Two Bohr-model diagrams side by side, both carbon. Carbon-12 (left) has a nucleus of 6 protons and 6 neutrons with 6 electrons; Carbon-14 (right) has 6 protons and 8 neutrons with the same 6 electrons. Both are carbon; they differ only in neutron count and mass number.](figures/carbon_isotopes.png)

- Carbon-12 is __________ (it never decays) — it is almost all of the carbon in nature.
- Carbon-14 is __________ (it decays at a fixed rate) — only a trace amount, and it is the "clock" used in radiocarbon dating.

**Average atomic mass — what the Periodic Table really lists:**

The Periodic Table lists **one** number for each element's mass, even though an element can have several isotopes. That number is the **average atomic mass** — a __________ average across all the naturally occurring isotopes.

- It is **not** a plain average — it is __________ by how __________ each isotope is.
- It always leans toward the __________ abundant isotope.

**Reading the lean (you do NOT compute this):**

| Element | Average atomic mass | Closer to… | More abundant isotope |
|---|---|---|---|
| Carbon | 12.011 | 12 | |
| Chlorine | 35.5 | | chlorine-35 |
| Boron | 10.81 | | |

**Step 4 — Reason about the average (no calculation).** Oxygen's average atomic mass on the Periodic Table is about **16.00**, very close to 16.

**Step 5 — Because / But / So:**

*Check your reasoning:* "because" should name what's the same (protons); "but" should name what's different (neutrons → mass number); "so" should state that they are isotopes of the same element.

**Reminder:** The average atomic mass on the Periodic Table is a *weighted* average — it leans toward the most abundant isotope. No single atom actually has the average mass; each real atom is a whole-numbered isotope.

**Key reference (from the 2025 NYS Reference Tables):**
Atomic number (= proton count) and average atomic mass: Periodic Table.
Mass number = protons + neutrons (a whole number, one per isotope).
