# Chemistry & Physics Curriculum Design

## Overview
Create complete Regents-level curricula for Chemistry and Physics aligned to the new NYSSLS standards-based assessments for Valley Stream Central High School District.

## Course Parameters
- 175 instructional days per course
- 42-minute periods, double period (84 min) every other day
- New NYSSLS standards-based Regents exams (2025+)

## Pedagogical Requirements
- **Hochman Literacy**: Sentence-level (Because/But/So, appositives, kernel sentences)
- **CRSE**: Culturally Responsive-Sustaining Education embedded throughout
- **Restorative Circles**: Opening circles at start of lessons (community building, sometimes content-connected)
- **Differentiation**: Tiered assignments, ELL scaffolds, IEP accommodations, extensions for advanced learners
- **CER Worksheets**: Claim-Evidence-Reasoning for each major topic

## Lesson Structure
1. Opening Circle (2-3 min)
2. Do Now (3-5 min)
3. Learning Target: "At the end of 42 minutes I can..."
4. 5E Instructional Sequence (Engage, Explore, Explain, Elaborate, Evaluate)
5. Hochman B/B/S activity integrated into Elaborate phase
6. CER or application task

## Deliverables Per Unit
- Unit Plan (.docx)
- Per lesson:
  - Lesson Plan (.docx) with circle prompt, do now, learning target, 5E, differentiation, CRSE, Hochman
  - Student Notes (.docx)
  - CER Worksheet (.docx)
- Labs/Investigations (student copy + answer key)
- Graphic Organizers as needed

## Lesson Plan Template Structure
1. Header: Unit, Lesson #, Title, Date range, PE codes
2. Opening Circle: 2-3 min prompt
3. Do Now: 3-5 min review/hook
4. Learning Target: "At the end of 42 minutes I can..."
5. Standards Alignment: PE, SEP, CCC, DCI
6. Materials & Preparation
7. 5E Instructional Sequence
8. Differentiation Box:
   - Approaching: scaffolds, word banks, sentence starters, modified texts
   - On-Level: standard expectations
   - Advanced: extension questions, deeper analysis
   - ELL: visual supports, bilingual glossary, simplified directions
   - IEP: extended time, chunked tasks, preferential seating
9. CRSE Connections
10. Hochman Integration (specific activity identified)

## CER Worksheet Template
1. Phenomenon or question prompt (with visual/data stimulus)
2. Claim: sentence starter scaffold
3. Evidence: data table or source
4. Reasoning: B/B/S sentence frame connecting evidence to claim

## Unit Plan Template
1. Unit title, duration, PE codes
2. Anchoring phenomenon
3. Essential questions
4. Unit sequence/pacing (lesson-by-lesson)
5. Standards map (PEs, SEPs, CCCs)
6. CRSE theme for the unit
7. Assessment overview (formative + summative)
8. Required investigations (if applicable)

## Implementation Phases
1. **Foundation**: Create .docx templates, build one sample unit per course
2. **Chemistry**: Units 1-11 sequentially, all materials per unit
3. **Physics**: Units 1-11 sequentially, all materials per unit
4. **Required Lab Investigations**: State-mandated investigations for each course

## Technical
- All documents generated as .docx using python-docx
- Consistent formatting and styles across all documents
- No per-lesson approval required; review at unit level
